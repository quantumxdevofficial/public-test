# System Design series — 30-day plan

Daily Short at ~11 PM Asia/Kolkata, run by the scheduled task "QuantumXDev System Design daily".
Each run makes the FIRST unchecked day below (not by date, so a failed day is retried next run), then ticks it.
Title format (exact): `(<day>/30) <Question> System Design` e.g. `(5/30) What Is a Load Balancer? System Design`.
Planned dates are a guide only.

Rules for this series (on top of RUNBOOK.md):
- Beginner-friendly, one idea per Short; it can briefly reference the previous day ("yesterday: caching").
- Use a real-world analogy (restaurant, traffic, library...) plus the flat tech components in shorts-kit/.
- End with a punchy loop line; the last caption chunk may tease tomorrow's topic.
- Description: hook + "Day <n> of 30 in the System Design series." + 6-8 hashtags incl. #systemdesign and #shorts.
- Slug: `sd-<day>-<short-name>`, e.g. `sd-05-load-balancer`.
- The general tech-explainer queue (topics.md) must NOT use any topic listed here.
